# Конституция проекта «Царапыч»

Принципы, которым обязаны соответствовать все спецификации, планы и код.
Изменение конституции — отдельный осознанный шаг с записью в журнале версий внизу.

## I. Мгновенность

Захват должен ощущаться мгновенным. От нажатия горячей клавиши до появления
рамки выделения — не дольше 200 мс; программа в фоне не должна заметно
нагружать систему (простой: ~0% CPU, память — десятки, а не сотни МБ).

## II. Приватность по умолчанию

- Никаких сетевых запросов без явного действия пользователя. Никакой телеметрии.
- Снимки хранятся только там, куда их положил пользователь.
- Инструменты скрытия данных (размытие/закраска) — первоклассная функция, а не довесок.

## III. Клавиатура прежде всего

Любое основное действие доступно с клавиатуры. Мышь — удобство, а не требование.

## IV. Минимум трения

- Основной сценарий «выделил → в буфере» — без единого лишнего клика и диалога.
- Разумные значения по умолчанию; настройки — для тех, кому надо, а не для всех.
- Работает «из коробки» без установки (portable) — [уточняется в спеке 001].

## V. Характер, но без навязчивости

Царапыч — персонаж с юмором (кот, «цапнул», «царапнул»), но шутки не мешают работе:
никаких всплывающих окон ради шутки, никаких звуков без возможности отключить.

## VI. Простота

Делаем меньше, но хорошо. Новая функция появляется только со своей спецификацией
и только если не нарушает принципы I–V.
