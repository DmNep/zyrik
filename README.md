# Зырик

Снимки экрана для Windows, Linux и macOS, которые никуда не утекают. Нажали клавишу, выделили кусок экрана, при желании дорисовали стрелку или подпись — и снимок уже в буфере обмена. Вставили его — и он исчез.

`Ctrl+PrtScr` → выделить мышью → `Enter` → `Ctrl+V` в чат.

Скачать: [последний релиз](https://github.com/DmNep/zyrik/releases/latest) ([Windows](https://github.com/DmNep/zyrik/releases/latest/download/zyrik-0.1.0.exe), [Linux x86_64](https://github.com/DmNep/zyrik/releases/latest/download/zyrik-0.1.0-linux-x86_64), [macOS Apple Silicon](https://github.com/DmNep/zyrik/releases/latest/download/zyrik-0.1.0-macos-aarch64.zip)).

## Что программа не делает

- Не открывает сеть. В коде нет сетевых вызовов, в зависимостях нет сетевых библиотек — это проверяет CI. На Linux соединения только местные: X-сервер и шина D-Bus сессии. `DISPLAY` с именем другой машины Зырик не принимает.
- Не пишет на диск ничего, кроме файла по `Ctrl+S`. Нет файла настроек, нет записей в реестре, нет «недавних файлов». Системный диалог «Сохранить как» Windows не используется: он сам записывает в реестр имя программы и последнюю папку. Вместо него у Зырика свой выбор папки.
- Не копит снимки. Снимок живёт в памяти, пока его не вставят или не отменят, потом память затирается нулями.
- Не отдаёт снимок в историю буфера и в облако. На Windows снимок помечен «не в журнал Win+V и не в облачный буфер», на Linux — пометкой для Klipper и других менеджеров буфера, на macOS — типами `Transient` и `Concealed`.
- Не отдаёт снимок фоновым программам, которые сами читают буфер. Снимок получает только вставка с зажатым `Ctrl` (на Маке `Cmd`). Отпустили клавишу — буфер пуст. Пока клавиша зажата, вставить можно несколько раз.
- Не добавляет себя в автозагрузку и не хранит настройки: всё задаётся параметрами в ярлыке.

PNG сохраняется без метаданных: в файле только картинка, без имени программы, пользователя и времени съёмки. Существующие файлы не перезаписываются: при совпадении имени добавляется `_2`, `_3`. Папки Зырик не создаёт.

## Как это устроено

```
горячая клавиша → снимок всех мониторов в память → окно выделения поверх всего
                                                        ↓
                                      зона, стрелки, рамки, подписи
                                        ↓                    ↓
                               Enter: буфер обмена      Ctrl+S: PNG в папку
                               (данные — по запросу,    (без метаданных,
                                одна вставка)            без перезаписи)
```

Всё, что решает — выделение, панель, пометки, отрисовка, выбор папки, — общее для трёх ОС и проверяется тестами без экрана (`src/session.rs`, `src/annot/`, `src/picker.rs`, `src/app.rs`). Код каждой ОС только снимает экран, показывает готовую картинку и передаёт мышь и клавиши: `src/win/`, `src/linux/` (X11), `src/mac/`. Шрифт подписей вшит в программу.

## Управление

После горячей клавиши экран замирает. Дальше:

- Мышью выделить зону. Тянуть за край или угол — менять размер, за середину — двигать. Стрелки двигают зону, `Shift`+стрелки — на 10 пикселей, `Ctrl`+стрелки меняют размер.
- Под зоной появляется панель: карандаш `P`, линия `L`, стрелка `A`, прямоугольник `R`, подпись `T`, цвет красный или синий `C`. С `Shift` линии ложатся ровно под 0, 45 и 90°, прямоугольник становится квадратом. Колёсико меняет толщину или размер подписи.
- `Ctrl+Z` — отменить, `Ctrl+Y` или `Ctrl+Shift+Z` — вернуть.
- `Enter`, `Ctrl+C`, двойной щелчок или ✓ — снимок в буфер.
- `Ctrl+S` — сразу PNG в последнюю папку: `--save-dir` или «Изображения».
- Дискета — свой выбор папки поверх снимка: `↑↓` и `Enter` — по папкам, `Backspace` — вверх, буква — к папке на эту букву, `Ctrl+S` — сохранить сюда, `Esc` — назад к снимку. Выбранная папка становится последней до выхода из программы.
- `Esc` или ✕ — закрыть. Правая кнопка сначала отменяет подпись или рисование, потом сбрасывает зону, потом закрывает.

На Маке вместо `Ctrl` — `Cmd`.

Значок о_О в трее (на Маке — в строке меню): «Зырнуть», «Зырнуть через 3 с», «О программе», «Выход».

## Параметры запуска

Настройки нигде не хранятся: их пишут в ярлык. `zyrik --help` печатает полную справку с путём к запущенному файлу.

- `--key <клавиши>` — горячая клавиша. По умолчанию `Ctrl+PrtScr`, на Маке `Cmd+Shift+2`. Например `--key Shift+PrtScr` или `--key Ctrl+Alt+F12`.
- `--save-dir <папка>` — куда сохранять по `Ctrl+S`.
- `--lang ru|en` — язык. По умолчанию — язык системы, иначе английский.

Если клавишу уже заняла другая программа, Зырик так и скажет и подскажет, как назначить другую. Снимать можно и из меню значка.

Поле «Объект» в ярлыке Windows:

```
"C:\путь\zyrik.exe" --key Shift+PrtScr --save-dir "D:\Снимки"
```

## Windows

Один файл `zyrik-0.1.0.exe`, установка не нужна. Подписи кода нет: SmartScreen может спросить подтверждение при первом запуске.

## Linux

Один файл `zyrik-0.1.0-linux-x86_64` для обычных дистрибутивов с glibc, работает в X11. Wayland — следующий этап. Ничего доустанавливать не нужно: X11 и D-Bus реализованы на Rust внутри программы.

Значок появляется в трее KDE Plasma, XFCE и Cinnamon. В GNOME — с расширением AppIndicator (в Ubuntu оно есть сразу). Если трея нет, работает горячая клавиша.

Проверено в Docker на KDE Plasma 5.27, XFCE 4.18 и GNOME 46 (Ubuntu 24.04), сценарии лежат в `tools/linux-desktops/`. Сценарий для CI — `tools/linux-test/`: он запускает Зырик под `strace` и проверяет, что на диск пишутся только сохранённые снимки, а все соединения местные.

## macOS

Архив `zyrik-0.1.0-macos-aarch64.zip` с `Зырик.app` для Apple Silicon, macOS 14 и новее. Распакуйте и перетащите в «Программы». Значок появляется в строке меню, в Dock Зырика нет.

Подпись временная (ad-hoc), без сертификата Apple. При первом открытии macOS может отказаться запускать программу. Тогда откройте её правой кнопкой → «Открыть» или подтвердите в «Системные настройки → Конфиденциальность и безопасность».

При первом снимке macOS спросит разрешение «Запись экрана и системного звука». Включите Зырик и запустите его снова. После обновления на новую версию разрешение придётся выдать заново: оно привязано к подписи.

## Сборка

Нужен Rust.

```
cargo test
cargo build --release
```

Готовый файл: `target/release/zyrik.exe` на Windows, `target/release/zyrik` на Linux. Для Windows нужен тулчейн `x86_64-pc-windows-gnu` и `windres` из MinGW: им в exe вшиваются значок и версия. `Зырик.app` собирается на Маке: `bash tools/macos/bundle.sh`.

Релиз собирает CI по тегу `v*` (`.github/workflows/release.yml`).

## Как ведётся работа

Проект идёт по Spec-Driven Development: сначала спецификация, потом план, потом задачи, потом код.

| Путь | Что там |
|---|---|
| `memory/constitution.md` | Принципы проекта: без сети, без записи на диск, без настроек на диске |
| `specs/001-core-capture/spec.md` | Что и зачем делаем |
| `specs/001-core-capture/plan.md` | Как делаем: стек, архитектура, решения |
| `specs/001-core-capture/tasks.md` | Задачи по фазам с итогами проверок |

Сделано: захват области, пометки, буфер, сохранение на Windows, Linux X11 и macOS. Дальше: Wayland, распознавание и закраска приватных данных на снимке (пароли, ключи, номера карт), снимок всего экрана и окна, задержка перед снимком.

## Ограничения

- Linux — только X11. Под Wayland (кроме приложений через XWayland) Зырик пока не работает.
- `--key-screen`, `--key-window`, `--clear-clipboard` и `--no-detect` уже принимаются, но пока не действуют: снимок экрана и окна, очистка буфера по таймеру и поиск приватных данных — следующие этапы. Любая клавиша сейчас открывает выделение области.
- На Маке первый снимок после запуска появляется за 0,3–0,9 с, следующие — за 0,1–0,2 с.
- Выбор папки показывает только папки; имя файла задаётся автоматически по дате и времени, новую папку из него не создать.

## English

Zyrik is a screenshot tool for Windows, Linux (X11), and macOS that never leaks. Press `Ctrl+PrtScr` (`Cmd+Shift+2` on a Mac), select an area, optionally draw arrows, boxes, or captions, and press `Enter`: the shot goes to the clipboard as a one-time paste. It is handed out only to a paste with `Ctrl`/`Cmd` held, and the clipboard is cleared when the key is released; background clipboard readers get nothing, and the shot is marked to stay out of clipboard history and cloud sync. `Ctrl+S` saves a metadata-free PNG to the last folder (`--save-dir` or Pictures) without overwriting files; the floppy button opens Zyrik's own folder picker, because the Windows save dialog writes the program name and folder to the registry. Zyrik never opens a network connection, writes nothing to disk except the files you save, keeps no settings (use launch options, see `zyrik --help`), and wipes the shot from memory after paste or cancel.
