# Задачи 001: Базовый захват экрана

**Спека**: [spec.md](spec.md) · **План**: [plan.md](plan.md) · **Создан**: 2026-11-20

## Как читать

- `T###` — номер задачи; выполняются по порядку, если не помечено иначе.
- `[P]` — можно делать параллельно с соседними `[P]` (разные файлы, нет зависимости).
- `[И#]` — к какой истории спеки относится; `[R#]` — какое исследование плана закрывает.
- **Тесты ядра пишутся до кода** (сначала красный тест, потом реализация).
- Каждая фаза заканчивается **контрольной точкой** — её проверяют руками, прежде чем идти дальше.
- Отмечаем выполнение: `- [x]`; `- [~]` — сделано частично (что осталось — в итогах плана).

## Зависимости между фазами

```
Ф0 ──► Ф1 ──► Ф2 ──► Ф3 ──┬──► Ф4 ──► Ф5 ──┐
                          │                ├──► Ф7
                          └──► Ф6 (ядро правил T061–T066 можно начинать сразу после Ф1) ──┘
```

Правила поиска «опасного» (T061–T066) не зависят от графики и OCR — их можно писать параллельно
с фазами 2–5, если работает больше одного человека или агента.
